# 01 - Introduction

## What is Windows Forms?
- A technology in .NET to build **graphical user interfaces (GUI)**.
- Used for **desktop applications** (not web) that run on **Windows**.
- Often used for enterprise applications (internal company tools).

## Windows Forms vs WPF

| | Windows Forms | WPF |
|---|---|---|
| Full name | Windows Forms | Windows Presentation Foundation |
| First version | .NET Framework 1.0 | .NET Framework 3.0 |
| UI is written in | C# (designer generates it) | XAML, then converted to C# |
| Graphics | Pixel based | Vector based (better quality and resolution) |

## Platform support
- Both work on the modern .NET runtime (.NET Core 3.0+ and .NET 5+).
- Both are **not cross-platform**. They run on **Windows only**.
